# lintframe

Lint digests and frame fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/lintframe/

## Install / run

```bash
git clone https://github.com/theworker02/lintframe.git
cd lintframe
node src/cli.js
node --test
```
